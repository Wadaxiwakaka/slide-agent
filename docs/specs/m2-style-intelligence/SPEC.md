# M2：可选择的视觉风格与确定性版式

## 用户目标与范围

让现有五种语义页面不再只呈现同一套蓝白版式：用户生成前可手动选择整套演示文稿的风格，也可让当前模型在规划内容的**同一次调用**中自动建议风格。整套 PPTX 保持统一、可编辑；确定性程序负责每页的具体布局。M2 优先改善视觉变化，不增加新的内容类型或布局类型。

M2 继续沿用本机单用户边界；没有登录、额度、网络公开访问保护，**不得直接公开部署**。M0 的五页 Demo 与 M1 的模型配置、三协议生成及可编辑下载保持可用。

## 风格与交互

- 生成表单新增风格选项：`auto`（界面默认）、`classic`（经典蓝，保持 M0/M1 基准）、`dark`（深色科技）、`warm`（暖色简报）。用户在**生成前**选择；没有预览或生成后的即时切换。
- `auto`：模型随 DeckSpec 在现有规划调用中返回建议风格；不得为了风格另发一次模型请求。手动指定时最终风格必须以用户选择为准，不受模型建议影响。
- 生成成功后仍下载原生可编辑 PPTX，同时显示本次实际风格名称。如果模型未给出有效风格，`auto` 回退到 `classic`，并明确显示“未识别风格，已使用经典蓝”；不得因**只有风格字段**无效而重试或额外计费。
- `POST /api/generate` 接受可选的 `styleChoice`。网页始终显式提交；为兼容现有本机 API 调用，缺省时按 `classic` 处理。非法选择应在发起模型请求前返回 400，不下载文件。成功 PPTX 响应使用安全、非敏感的风格 ID 响应头供网页显示，必要时附带回退标记；失败仍沿用安全 JSON 错误。

## 规划与模型边界

- `DeckSpec` / `SlideSpec` 的字段、五种 `layout` 类型及 Zod 核心模型**不变**。风格 ID 是规划结果的独立元数据，不放进 DeckSpec，也不含坐标或 PptxGenJS 对象。
- Planner 在原有一次模型调用中请求形如 `{ "deck": <DeckSpec>, "styleId": "classic|dark|warm" }` 的 JSON。先单独验证 `deck` 的 schema、页数及首张 `title`，再解析风格；模型只返回旧版合法 DeckSpec 或漏掉/写错风格时，视为有效内容 + 风格回退，不静默丢掉文稿。手选模式覆盖模型建议。
- JSON 无法解析或 DeckSpec 无效时，仍仅对同一个模型按 M1 策略重试一次；连接/鉴权错误不重试。复用 M1 的 90 秒超时、256 KiB 响应上限、无重定向及密钥安全规则。

## 主题与布局

- 主题层提供三个内建预设的配色、文字对比、字型/字号和布局参数；不引入外部字体、图片、主题插件或第三方布局依赖。深色方案保证文字可读；主题选择不影响语义内容。
- 布局层针对每种现有页面类型（`title`、`title_body`、`three_cards`、`comparison`、`process`）提供有区别的确定性构图，而不只是替换颜色：例如标题位置、内容栏数、卡片层次和流程方向。变体由风格及页面内容规则选择，不随机、不要求 AI 输出几何坐标；同一 DeckSpec + 风格总得到相同元素及几何位置。整套文稿使用同一风格，不逐页混搭。
- 元素仍是可编辑文字和形状；保留边界校验。文字较密时采取保守的间距/字号或简化排布，不能静默截断文字；如果确定性检查判定无法安全排版，返回可操作错误而非损坏 PPTX。M2 不声称已经具备 M3 的实际幻灯片预览或 M4/M5 的完整视觉 QA。
- `/api/demo` 仍使用原 `classic` 主题、五页内容和可编辑输出；不依赖模型或风格配置。

## 验收

- 三种风格的同一五页样例在每种页面类型上呈现可辨别的版式差异，整套一致；`classic` 与 M0 的 Demo 外观保持兼容。人工打开或导出样例检查标题、卡片、对比和流程文字可读。
- 离线模拟模型响应验证：自动识别、手动覆盖、无效/缺少风格回退并提示、旧版合法 DeckSpec 回退、非法选项无模型请求、无效 DeckSpec 最多一次重试、网络失败不重试。**只有风格无效**时仍只调用模型一次。
- 相同 DeckSpec + 风格的布局结果完全相同，元素在画布范围内；长中文/英文内容不得静默丢失。生成的 PPTX ZIP 中页数正确，文本与形状可编辑，且不同预设确实产生不同主题/几何结果；M0/M1 全量测试仍通过。
- `pnpm test && pnpm lint && pnpm build` 通过。浏览器验证风格选择、回退提示和下载，不自动调用付费模型；有用户自备有效密钥时才另做人工真实调用。

## 明确延期

- **生成后不再次调用模型即可切换风格**：需保留当次 DeckSpec，并提供重新渲染/下载交互；用户要求记录为后续能力，**不属于 M2**。
- 生成制作环节的进度可视化、幻灯片预览、真正的新布局类型/图表/图片、模型自动路由、数据库与公网部署也不属于 M2。后续事项已在路线图（PR #1）记录；本规格同时保留生成后换肤的约束，不依赖 PR #1 合并才能阅读。
