# SlideAgent 产品目标

SlideAgent 是一个面向需要快速制作**可编辑**演示文稿的用户的开源项目，也用作工程能力展示。用户输入主题或材料后，系统最终应能完成规划、设计、生成、预览、验证和修复，输出可在 PowerPoint 中继续编辑的 PPTX。

核心原则：AI 决定内容、叙事与设计意图；确定性程序决定布局、渲染和几何约束。不能只是 LLM 文字填模板。

**当前 M0** 不接入 AI，只验证从结构化 DeckSpec 经布局到可编辑 PPTX 的链路。成功标准是五页示例可下载、文本与形状可编辑、基本几何规则有测试、构建与测试通过。

长期目标包括主题/文本/文档输入、研究、图表和图片、视觉 QA、修复及自然语言编辑；当前不做登录、支付、数据库、PDF/DOCX、研究、LLM 或分布式服务。
