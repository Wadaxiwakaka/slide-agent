# SlideAgent 产品目标

SlideAgent 是一个面向需要快速制作**可编辑**演示文稿的用户的开源项目，也用作工程能力展示。用户输入主题或材料后，系统最终应能完成规划、设计、生成、预览、验证和修复，输出可在 PowerPoint 中继续编辑的 PPTX。

核心原则：AI 决定内容、叙事与设计意图；确定性程序决定布局、渲染和几何约束。不能只是 LLM 文字填模板。

**M0 已完成**：无 AI 的五页示例验证了 DeckSpec → 布局 → 可编辑 PPTX 的链路。**M1 已完成**：本机单用户选择已配置的模型 API，从主题/文本生成经校验的 DeckSpec。**当前 M2**：在不修改 DeckSpec 和五种语义页面类型的前提下，自动或手动选择经典蓝、深色科技、暖色简报，确定性布局输出统一且可编辑的 PPTX；M0 示例保持可用。当前版本不可直接公开部署。

长期目标包括文档输入、研究、图表和图片、视觉 QA、修复及自然语言编辑；内容叙事优化、时间轴/数据重点页等新语义页面、生成后无需 AI 换肤以及制作过程可视化留待后续。当前不做登录、支付、数据库、PDF/DOCX、研究、模型自动路由或分布式服务。
