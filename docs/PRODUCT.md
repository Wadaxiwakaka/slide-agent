# SlideAgent 产品目标

SlideAgent 是一个面向需要快速制作**可编辑**演示文稿的用户的开源项目，也用作工程能力展示。用户输入主题或材料后，系统最终应能完成规划、设计、生成、预览、验证和修复，输出可在 PowerPoint 中继续编辑的 PPTX。

核心原则：AI 决定内容、叙事与设计意图；确定性程序决定布局、渲染和几何约束。不能只是 LLM 文字填模板。

**M0 已完成**：无 AI 的五页示例验证 DeckSpec → 布局 → 可编辑 PPTX。**M1 已完成**：本机单用户接入三协议模型 API。**当前 M2 内容阶段**：保留三套风格，增加先审阅/编辑/排序大纲再确认生成 PPTX 的两阶段流程，并在用户原始材料支持时生成时间轴或数据重点页；模型输出与编辑中的日期、数值由服务端校验原文，不代表自动事实核查。旧版生成 API 和 M0 示例仍可用。当前版本不可直接公开部署。

长期目标包括文档输入、研究、图表和图片、视觉 QA、修复及自然语言编辑；生成后无需 AI 换肤与制作进度可视化仍待后续。M3 才提供下载前预览；当前不做登录、支付、数据库、PDF/DOCX、研究、模型自动路由或分布式服务。
